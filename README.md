# IPTV Player

**版本：1.1.0**

轻量级 Android IPTV 播放器，手机 / TV 双端原生适配，基于 libVLC 播放内核与 Jetpack Compose 原生 UI 构建。

## 下载安装

本仓库仅提供安装包分发，不含源代码。安装包位于 [`apk/1.1.0/`](./apk/1.1.0) 目录，按设备类型与 CPU 架构选择对应文件：

| 文件 | 适用设备 |
|---|---|
| `IPTV-mobile-arm64-v8a-1.1.0.apk` | 手机 / 平板（64 位，主流机型） |
| `IPTV-mobile-armeabi-v7a-1.1.0.apk` | 手机 / 平板（32 位，老旧机型） |
| `IPTV-tv-arm64-v8a-1.1.0.apk` | Android TV / 电视盒子（64 位） |
| `IPTV-tv-armeabi-v7a-1.1.0.apk` | Android TV / 电视盒子（32 位） |

不确定架构时，2019 年后的设备绝大多数选 `arm64-v8a` 即可。

**安装步骤**：下载对应 APK → 手机/TV 上允许「安装未知来源应用」→ 点击安装。覆盖安装旧版本无需卸载，数据自动保留。

历史版本：[`apk/1.0.0/`](./apk/1.0.0)

## 功能特性

- **直播播放**：libVLC 内核，支持 HLS / TS / m3u8 等主流直播流格式，硬件解码
- **EPG 节目单**：7 天 XMLTV 电子节目指南，播放页侧边栏快速查看
- **频道管理**：订阅源导入（m3u）、频道分组、搜索、排序
- **多源切换**：多订阅源自由切换，秒切不重复下载；编辑源地址自动重新拉取；源频道为空时自动补一次刷新
- **收藏**：常用频道一键收藏，独立收藏页；删除源或刷新源后自动清理失效收藏
- **画面卡顿自愈**：播放停滞自动检测与重连
- **画中画**：手机端 PiP 悬浮播放
- **双端 UI**：手机端与 TV 端均为 Compose 原生实现，支持深色 / 浅色主题
- **截图预览**：频道封面快照自动生成

## 系统要求

- Android 6.0（API 23）及以上
- CPU：armeabi-v7a 或 arm64-v8a

## 安全与混淆

- **代码混淆**：Java/Kotlin 层经 R8 混淆与优化；Native 层（安全校验模块）经 OLLVM / O-MVLL 控制流混淆，发布前全量开启
- **数据库加密**：本地数据（收藏、订阅、EPG 缓存）使用 SQLCipher 整库 AES-256 加密
- **签名与加固**：V1 + V2 + V3 全方案签名；运行期校验签名完整性（证书哈希比对），检测调试器 / Frida / Hook 框架，支持监控 / 警告 / 阻断三种启动策略
- **日志剥离**：Release 包移除全部应用层日志
- 本应用不收集、不上传任何用户数据

## 合规声明

本应用仅为通用播放器工具，**不内置、不提供、不推荐任何直播源或内容**；用户需自行添加其合法获得授权的订阅源，并对所播放内容承担相应责任。
